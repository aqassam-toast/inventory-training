Ingredient Import — Claude skill
Turns a customer's ingredient, price, or inventory files into a filled-out import workbook. Handles messy spreadsheets, CSV exports, and vendor order-guide PDFs.
Skill

You don't need the template file to use the skill. It generates the import workbook itself, so the only thing to hand over is the customer's own price or ingredient files — one file or several. Multiple files are combined into a single import, with duplicate rows dropped and anything uncertain flagged in a review sheet. To install it, download the skill and add it to Claude, then attach the customer's files.
